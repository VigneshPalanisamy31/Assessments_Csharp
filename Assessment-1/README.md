### To-Do List Application
# A simple query Manager application that allows you to add filters,sorting,join .Built as a console application using c#.

## Features:
  Involves the development of a simple console-based To-Do application.
 
## Implementation Details
 
The To-Do allows different functionalities to manipulate the to-do tasks of user. The various functionalities implemented in To-Do Application are as follows:
# 1.Register User 
  -  allows to register a new user with id name and password
 # 2.Login User 
 - performs user authentication and enables functionalities
 # To-Do tasks:
 1. Add - To add To-Do tasks for the user.
 2. Edit  To edit To-Do tasks for the user.
 3. Update Status - To update the status of a To-Do task for the user.
 4. View - To view To-Do tasks of a user.
 5. Delete - To delete a To-Do task of  the user.
