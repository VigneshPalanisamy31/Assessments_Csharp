### Boiler Controller Application
# A simple boiler controller application that allows you to work with boiler as a console application using c#.

## Features:
  Involves the development of a simple console-based boiler controller application.
 
## Implementation Details
 
The Boiler Controller allows different functionalities to work with the boiler. The various functionalities implemented in Boiler Application are as follows:
&emsp; &emsp; 1. Start Boiler Sequence- to check required conditions and start the boiler.
&emsp; &emsp; 2. Stop Boiler Sequence- to stop the boiler if it's in operational mode.
&emsp; &emsp; 3. Simulate Boiler Error- to simulate error if the boiler is in operational mode.
&emsp; &emsp; 4.Toggle Run Interlock Switch- to toggle between open and closed.
&emsp; &emsp; 5.Reset Lockout - to get the boiler ready.
&emsp; &emsp; 6. View Event Log - to view logs of all events.
&emsp; &emsp; 7. Exit Application - to exit the boiler controller.
